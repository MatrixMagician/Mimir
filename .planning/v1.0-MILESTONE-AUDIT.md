## Tech Debt

**WARNING-1 — Path-glob suppression not applied to `--git`/`--staged` (and thus the pre-commit hook).**
See the structured `tech_debt` block above. Affected: SUP-02 (working-tree only), SUP-04
(default-exclude glob half; allowlist half is fine), IFACE-03 (hook inherits the gap).
Severity: WARNING — over-reporting, not data loss; no broken flow; Phase 3 acceptance criteria
explicitly required only inline-ignore for git/staged, which is honored and tested.

Recommended remediation (future cleanup phase or v2): thread the `PathMatcher` into
`gitscan.ScanHistory`/`ScanStaged`, filter on `finding.File`, and add a git+staged path-glob
test in both directions. Alternatively, document the deviation if flagging ignored-path secrets
in history/staged is intended behavior.
