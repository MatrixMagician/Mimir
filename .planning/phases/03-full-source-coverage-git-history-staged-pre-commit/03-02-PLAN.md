<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo path → `git diff --staged` process | Untrusted repo path crosses into a spawned subprocess |
| staged diff content → go-gitdiff → engine | Attacker-influenced staged lines parsed and regex-scanned |
| matched secret → Finding → output | Raw secret must stay redacted at the `finding.New` boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering | command.go staged spawn | mitigate | `exec.CommandContext(ctx, "git", args...)` explicit arg slice with `-C <repoRoot>`; never `sh -c` (Security V12). |
| T-03-07 | Information Disclosure | staged findings output | mitigate | Findings via `engine.ScanLine`→`finding.New` (redacts); empty PatchHeader means no commit metadata leaks; reflect-guard covers fields. |
| T-03-08 | Denial of Service | regex over staged diff | mitigate | RE2 linear-time (already locked); benchmark gate bounds wall time. |
| T-03-09 | Denial of Service | benchmark / streaming memory | mitigate | `BenchmarkHistoryMem` asserts heap delta does not scale with history length — regression gate for the bounded-memory invariant (criterion 2). |
</threat_model>
