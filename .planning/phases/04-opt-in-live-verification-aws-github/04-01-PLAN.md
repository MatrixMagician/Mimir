<objective>
Add the `Finding.Verification` field and build the side-channel raw-secret carry: a
`map[fingerprint]rawSecret` populated at the ONE site where the raw value still exists
(`engine.ScanLine`), threaded out through `Scanner.Scan`, `gitscan.ScanHistory`, and
`gitscan.ScanStaged` return signatures. This is the load-bearing plumbing that lets the
Wave 2 verifier obtain the real secret to make an API call WITHOUT ever storing it on the
serializable `Finding` type.

Purpose: Preserve the redact-at-boundary invariant (raw secret off-struct, never marshalled,
never logged) while still making the raw value reachable for opt-in live verification.
Output: `Verification` type + omitempty `*Verification` field on `Finding`; raw side-channel
map threaded through all three scan-source return tuples; guard tests for off-struct carry
and JSON omit-by-default.
</objective>
