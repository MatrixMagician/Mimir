<objective>
Build the `internal/verify` package: a `Verifier` interface, a three-state `Status` enum, a
registry keyed by detection rule ID, the AWS verifier (static-credential STS GetCallerIdentity,
provably ambient-free), the GitHub verifier (bare net/http GET /user with rate-limit
classification), and the `Run` orchestrator with a per-(provider,secret) cache and a bounded
errgroup. This is the network boundary — every SDK/HTTP error is sanitized to {provider, reason}
and the secret never appears in any log or error.

Purpose: Turn the raw secret (carried via the Plan 01 side channel) into an active/inactive/unknown
label via read-only provider calls, with the safety controls (no ambient creds, no retry storms,
no secret leakage) that a security tool making calls with other people's credentials requires.
Output: `internal/verify` package + AWS/GitHub modules added to go.mod + full unit test suite
(error-code classification table, httptest harness, cache dedup, no-secret-in-error, no-ambient-creds).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| verify package → AWS STS / GitHub API | Outbound network calls made with OTHER PEOPLE'S credentials; the raw secret is the call payload |
| SDK/HTTP error → caller | Provider errors can embed request context; they must be sanitized before crossing back |
| operator environment → AWS verifier | Ambient AWS_* env / ~/.aws must NEVER influence the result (false active) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-leak | Information Disclosure | verifier error/log | mitigate | sanitizedError{provider,reason} only; NEVER %w/%v an SDK/HTTP error; token never in URL/query. Test: TestNoSecretInError. (BLOCK-WORTHY: secret leakage) |
| T-04-active | Spoofing/Tampering | AWS verifier | mitigate | Direct sts.New with static creds; NO LoadDefaultConfig; BaseEndpoint pinned. Test: TestNoAmbientCreds (bogus AWS_* env ignored). (BLOCK-WORTHY: false active from operator creds) |
| T-04-url | Information Disclosure | GitHub request | mitigate | Token only in Authorization header, never in URL/query. Grep gate in acceptance criteria. |
| T-04-dos | Denial of Service | GitHub rate-limit | mitigate | errgroup SetLimit(5); Retry-After honored once then unknown (no loop, Pitfall 3); 5s per-call timeout. Tests: TestRetryAfterOnce, classify-timeout. |
| T-04-ssrf | Tampering | fixed hosts | accept | Only fixed hosts (api.github.com / sts.amazonaws.com); the secret is payload, never the URL — no attacker-controlled host. Low risk. |
| T-04-SC | Tampering | go get aws-sdk-go-v2 | mitigate | First-party github.com/aws modules (RESEARCH Package Legitimacy Audit, approved); blocking-human checkpoint before install; `go mod verify` after. |
