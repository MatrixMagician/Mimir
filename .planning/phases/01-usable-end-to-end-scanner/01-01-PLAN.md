## Phase Goal

**As a** developer auditing a codebase, **I want to** run `mimir scan ./repo` and immediately see accurate, redacted findings with a scan-stats summary, **so that** I can identify leaked secrets without the scanner itself leaking secret values.

<objective>
This plan delivers the Walking Skeleton: the thinnest real end-to-end path
through the entire Mimir pipeline. After this plan, a developer can build the
binary and run it against testdata to see real redacted findings, a summary
line, and correct exit codes.

Purpose: Prove the full stack works — file walk → Aho-Corasick keyword gate →
RE2 match → Finding redacted at boundary → human output → exit code. Every
later plan thickens this skeleton without changing its architecture.

Output: Working `mimir` binary, Finding data model, aws-access-token rule active,
human formatter, exit code contract, test scaffolding for all packages.
</objective>

    internal/finding/finding.go — package finding:
      Finding struct with fields: RuleID, Description, File, Line, Column, Match, Secret, Fingerprint, Entropy float32, IsHeuristic bool. JSON tags as specified in RESEARCH.md §JSON Finding Schema. NEVER add a field holding the raw secret value.

      RedactSecret(secret string) string:
        const minVisibleLen = 16 (per D-05 threshold from RESEARCH.md)
        If len(secret) < minVisibleLen → return "[REDACTED]"
        Else → secret[:4] + "****...****" + secret[len(secret)-4:]

      computeFingerprint(repoRelPath, ruleID, rawSecret string) string:
        normalizedPath := filepath.ToSlash(repoRelPath)
        h := sha256.Sum256([]byte(rawSecret))
        hashPrefix := hex.EncodeToString(h[:])[:16]
        return normalizedPath + ":" + ruleID + ":" + hashPrefix

      New(ruleID, file string, line, col int, rawSecret, matchContext string, isHeuristic bool) Finding:
        fp := computeFingerprint(file, ruleID, rawSecret)
        redactedMatch := strings.ReplaceAll(matchContext, rawSecret, RedactSecret(rawSecret))
        return Finding{RuleID: ruleID, File: file, Line: line, Column: col,
          Match: redactedMatch, Secret: RedactSecret(rawSecret), Fingerprint: fp,
          IsHeuristic: isHeuristic}
        // rawSecret goes out of scope here; NOT stored in any field

      Import ahocorasick "github.com/BobuSumisu/aho-corasick".
      Engine struct: trie *ahocorasick.Trie, rules []config.Rule.
      NewEngine(rules []config.Rule) *Engine:
        Build trie with ahocorasick.NewTrieBuilder().AddStrings(keywords).Build().
        Keywords: for each rule, append all rule.Keywords lowercased to a []string.
        Store compiled rules in engine.
      ScanLine(line, filePath string, lineNum int) []finding.Finding:
        lineLower := strings.ToLower(line)
        Fast path: if engine.trie.MatchFirstString(lineLower) == nil { return nil }
        Full match: matches := engine.trie.MatchString(lineLower)
        Build candidateRules from keyword matches (see RESEARCH.md §Full Pipeline).
        For each candidateRule:
          Apply rule.CompiledRegex on ORIGINAL (not lowercased) line.
          Extract secret from SecretGroup (default group 1 if SecretGroup==0).
          Check entropy: if rule.Entropy > 0 && shannonEntropy(rawSecret) <= rule.Entropy { continue }
          Check rule allowlists: if rawSecret matches any allowlist regex { continue }
          Call finding.New(ruleID, filePath, lineNum, col, rawSecret, fullMatch, rule.IsHeuristic).
        Return findings.

    internal/scanner/scanner.go — package scanner:
      Stats struct: FilesScanned int, Duration time.Duration.
      Scanner struct: engine *detect.Engine, cfg *config.Config.
      New(engine *detect.Engine, cfg *config.Config) *Scanner.
      Scan(ctx context.Context, paths []string) ([]finding.Finding, Stats, error):
        g, ctx := errgroup.WithContext(ctx); g.SetLimit(runtime.GOMAXPROCS(0))
        var mu sync.Mutex; var allFindings []finding.Finding; start := time.Now()
        Walk each path with filepath.WalkDir:
          On .git directory entry: return filepath.SkipDir
          On regular file: check size vs cfg.MaxFileSizeMB*1024*1024; if oversized, skip (log to stderr at verbose level)
          g.Go(func() error { findings, _ := s.scanFile(ctx, path); mu.Lock(); allFindings = append(...); mu.Unlock(); return nil })
        g.Wait()
        Sort allFindings deterministically: by File, then Line, then Column (sort.Slice with <).
        Return allFindings, Stats{FilesScanned: count, Duration: time.Since(start)}, err.
      scanFile(ctx, path string) ([]finding.Finding, error):
        Read file; peek first 512 bytes for isBinary(); if binary return nil.
        Read full content; split by lines; for each line call engine.ScanLine(line, repoRelPath, lineNum+1).
        repoRelPath: make path relative to the scan root (use filepath.Rel), then filepath.ToSlash.
