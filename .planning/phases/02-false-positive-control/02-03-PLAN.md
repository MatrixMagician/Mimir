<objective>
Deliver the path-exclusion vertical slice (SUP-02 + SUP-04): a developer drops a
`.mimirignore` at the scan root (gitignore-style, `**` + `!negation`) and noisy
paths vanish from `mimir scan`; and out-of-the-box defaults (vendor/, node_modules/,
*.min.js, lockfiles, …) keep a real dirty repo quiet on first run with no config
(criterion 2), with a master toggle to disable all defaults. Excluded paths are
walk-pruned (never opened, D-05) and reported only as an aggregate count (D-13).

Purpose: Default path noise is the single biggest first-run false-positive source.
This slice makes Mimir usable on a real repo immediately and is the second
suppression layer (path-prune precedes inline/allowlist/baseline in attribution).
Output: internal/suppress/pathmatch.go (+ test), the config toggle key, the
walk-prune gate + excluded-count wiring in scanner, .mimirignore loading in scan.go,
and CLI tests for defaults + negation + the toggle.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-supplied .mimirignore patterns → glob matcher | Untrusted glob patterns parsed by doublestar |
| .mimirignore path argument → os.ReadFile | User-controlled file path at scan root |
| untrusted repo paths → doublestar.Match | Repo-relative path strings matched against globs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Denial of Service | malformed/pathological .mimirignore glob | mitigate | doublestar is glob (not backtracking regex — CLAUDE.md forbids regexp2); validate every pattern with `doublestar.ValidatePattern` at construction and reject with a clear error; no unbounded recursion |
| T-02-07 | Tampering (trust erosion) | over-broad default excludes hide a real secret | mitigate | `!negation` per-pattern recovery + `use_default_allowlists=false` master toggle (D-07); ALWAYS show the `N paths excluded` count (D-11/D-13) so exclusion is never silent |
| T-02-08 | Tampering | malformed .mimirignore silently disables all exclusion | mitigate | A pattern that fails ValidatePattern exits 2 (fail loud, mirrors broken-config → exit 2; Security V14) — never silently scan-everything or scan-nothing |
| T-02-09 | Information Disclosure | path traversal via .mimirignore path | accept | `.mimirignore` is read only from `filepath.Join(scanRoot, ".mimirignore")`; Mimir only READS local files the user already controls; no traversal amplification (Security Domain) |
</threat_model>
