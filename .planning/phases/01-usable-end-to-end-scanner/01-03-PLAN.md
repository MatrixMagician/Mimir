    loadFromBytes(data []byte) (*RawConfig, error):
      Use toml.Unmarshal(data, &raw). On toml.DecodeError, format as "config parse error at line N col M: ...". On other error, wrap with %w.

    compile(raw *RawConfig) (*Config, error):
      For each rule in raw.Rules:
        re, err := regexp.Compile(rule.Regex)
        if err != nil:
          return nil, fmt.Errorf("rule %q: invalid regex %q: %w\n  (RE2 does not support lookaheads or backreferences; use entropy + allowlists instead)", rule.ID, rule.Regex, err)
        Compile allowlist regexes similarly.
      Build Config.Rules from validated rules. Set MaxFileSizeMB = 10 as default.
      Build Config.GlobalAllowlists from raw.Allowlists.
      NOTE: NoEntropy and Verbose are NOT set from the TOML file — they are set by cmd/scan.go from
      CLI flags after LoadConfig returns. compile() leaves them at their zero values (false).

    mergeConfigs(base, overlay *RawConfig) *RawConfig:
      Start with base rules + allowlists. Append overlay rules. Apply overlay disabled_rules (remove matching IDs from merged rules list). Merge allowlists.

    LoadConfig(flagPath string, scanRoot string) (*Config, error):
      Algorithm (per RESEARCH.md §Config Discovery):
        if flagPath != "":
          data, err := os.ReadFile(flagPath)
          if err: return nil, fmt.Errorf("config file %q: %w", flagPath, err)  // explicit path: missing → error
          raw, err := loadFromBytes(data); if err: return nil, err
          if raw.Extend.UseDefault:
            defaultRaw, _ := loadFromBytes(config.DefaultConfig)
            merged := mergeConfigs(defaultRaw, raw)
            return compile(merged)
          return compile(raw)
        projectConfig := filepath.Join(scanRoot, ".mimir.toml")
        if _, err := os.Stat(projectConfig); err == nil:
          data, _ := os.ReadFile(projectConfig)
          raw, err := loadFromBytes(data); if err: return nil, err
          if raw.Extend.UseDefault:
            defaultRaw, _ := loadFromBytes(config.DefaultConfig)
            merged := mergeConfigs(defaultRaw, raw)
            return compile(merged)
          return compile(raw)
        // Fall through: embedded defaults only
        return LoadDefault()

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| User-provided TOML config (--config flag) → LoadConfig() | Untrusted user file crosses into RE2 compilation |
| Project .mimir.toml in scan root → LoadConfig() | Untrusted project config (could be from attacker-controlled repo) |
| Finding struct → JSON encoder | Redacted Finding fields flow to JSON output channel |
| JSON output → stdout | Redacted values only; OUT-03 self-scan test asserts no raw secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-01 | Tampering | `internal/config/config.go` LoadConfig() — user-supplied TOML | mitigate | All regex patterns from user config are passed through regexp.Compile (RE2 validation) at load time. Invalid pattern → non-nil error → os.Exit(2) in runScan. User cannot inject arbitrary computation via regex (RE2 is safe). |
| T-03-02 | Information Disclosure | `internal/output/json.go` WriteJSON | mitigate | JSON encoder writes Finding.Secret which is already redacted by finding.New(). TestJSONNoSecretLeak integration test asserts no raw fixture secret appears in JSON output. |
| T-03-03 | Elevation of Privilege | `extend.path` in user config — file path traversal | accept | Phase 1: extend.path is not implemented (only use_default + disabled_rules + inline [[rules]]). Path traversal via extend.path is a Phase 2 concern when path-based extends land. Document the deferred mitigation: resolve to absolute path and warn on paths outside project root. |
| T-03-04 | Information Disclosure | Error messages from config parse errors | mitigate | Config error messages include file path and rule ID only. The error from regexp.Compile contains the regex pattern (developer-authored, not a secret) — acceptable. Error messages MUST NOT include file line content. |
| T-03-05 | Denial of Service | config.LoadConfig() merging large extend chain | accept | v1 only supports one level of extend (no recursive path-based extends). Bounded computation; no chain depth to exploit. |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No new dependencies in Plan 03. go mod verify confirms checksums from go.sum. |

**Residual:** T-03-03 (extend.path traversal) is residual/deferred — extend.path is NOT implemented in Phase 1 (only use_default and disabled_rules). Marked as deferred-to-Phase-2 when path-based extends land.
</threat_model>
